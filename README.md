# Awesome CheapAIModel [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of SDKs, frameworks, apps and tools that work with the [CheapAIModel](https://cheapaimodel.com) API.

Since CheapAIModel is OpenAI-compatible, anything that supports a custom OpenAI base URL should work.

## Official

- [python-sdk](https://github.com/cheapaimodel/python-sdk) - Python client.
- [typescript-sdk](https://github.com/cheapaimodel/typescript-sdk) - TypeScript / JavaScript client.
- [examples](https://github.com/cheapaimodel/examples) - Ready-to-run code samples.
- [docs](https://github.com/cheapaimodel/docs) - API documentation.

## Frameworks

- [LangChain](https://github.com/langchain-ai/langchain) - Use `ChatOpenAI` with a custom `base_url`.
- [LlamaIndex](https://github.com/run-llama/llama_index) - Use the OpenAI-like LLM class with a custom API base.
- [Vercel AI SDK](https://github.com/vercel/ai) - Use `createOpenAI({ baseURL })`.
- [LiteLLM](https://github.com/BerriAI/litellm) - Point an `openai/` model at a custom `api_base`.

## Chat apps

- [Open WebUI](https://github.com/open-webui/open-webui) - Self-hosted chat UI; add an OpenAI-compatible connection.
- [LibreChat](https://github.com/danny-avila/LibreChat) - Multi-provider chat UI with custom endpoints.

## Developer tools

- [Continue](https://github.com/continuedev/continue) - Open-source AI coding assistant for VS Code and JetBrains.
- [Aider](https://github.com/Aider-AI/aider) - AI pair programming in your terminal.
